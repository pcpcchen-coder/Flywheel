# 研究資料快照

本目錄保存本次研究使用的查詢結果快照，供追溯與後續更新；不是完整全球資料庫。

| 檔案群組 | 內容 | 使用邊界 |
|---|---|---|
| `scholar_review.csv` | 飛輪綜述、系統與應用文獻 | 以 DOI／期刊頁核對核心引用；搜尋結果不代表完整文獻計量 |
| `scholar_battery.csv` | 飛輪－鋰電混合、功率分配與衰退 | 研究結論不可直接外推為所有場站的壽命改善倍率 |
| `scholar_hydrogen.csv` | 飛輪－氫能、電解槽與微電網研究 | 多為模擬或示範，不能當成大型商業實績 |
| `scholar_bearing.csv` | 磁軸承、超導、低功耗與待機損耗 | 部件研究需與整機輔機功耗一起判讀 |
| `tyc_*.csv` | 中國企業工商主體查詢快照 | 存續與註冊資本不等同財務健全、履約或產品驗收 |
| `tyc_patents_*.csv` | 企業與技術關鍵字專利樣本 | 不是全球普查；法律狀態、同族與權利項須逐件核查 |

## 時間與更新

- 天眼查工商與專利快照：2026-10-30。
- 學術搜尋結果：本次研究期間取得；核心文獻以 DOI、期刊頁或原文摘要再次核對。
- 後續更新應保留查詢日期、查詢條件與原始快照，避免覆蓋後無法比較差異。
