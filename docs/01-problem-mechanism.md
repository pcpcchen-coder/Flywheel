# 01 · 問題機理：AIDC 動態負載如何傷電網

> 本章整理自 v1／v2 簡報與研究筆記。標「示意」的數字來自自建示意模型（100 MW AIDC、PCC 161 kV），不是量測或廠商數據。

## 1.1 同步訓練讓整座機房變成一個方波

大型語言模型（LLM）訓練採用**同步訓練**：每一輪迭代先「計算」（前向＋反向傳播，tensor core 滿載，GPU 功率接近 TDP），再「通訊」（all-reduce 交換梯度，GPU 幾乎閒置）。所有 GPU 在同一時刻切換階段，所以各卡的功率變化不會互相抵消，而是整齊疊加到電網上。

| 項目 | 數值 | 來源 |
|---|---|---|
| 單卡 H100 | 約 700 W ↔ 140 W | arXiv 2508.14318 |
| 5 萬張 GPU 的作業 | 約 35 MW ↔ 7 MW | 同上 |
| 迭代週期 T_iter | 約每秒一次到每數十秒一次（示意取 1.4 s，f_iter ≈ 0.71 Hz） | 同上 |
| GPU 占伺服器功率 | > 50%（GB200） | 同上 |
| 單一作業規模 | 可超過 10 萬張 GPU，擺盪可達數十 MW | 同上 |
| EDP 尖峰 | 約 50 ms、可達 1.1 × TDP | 同上 |
| 階躍事件 | 作業啟動、checkpoint、當機：數十毫秒內跳 50–70 MW | 同上；EasyRider（arXiv 2604.15522） |

示意模型的負載：`P = base + gpuPeak · g(t)`，base 15 MW、gpuPeak 85 MW，計算占比 64%、通訊時 g = 0.22，因此在 **35 ↔ 100 MW** 之間擺盪，一階邊緣時間常數 5 ms（v2）／12 ms（v1）。

**負載不是「有時無」，而是高低擺盪**：底部約 35% 永遠在；問題在於擺幅大、頻率落在敏感頻段、而且邊緣只有幾毫秒。

## 1.2 功率擺盪 → 電流調幅 → 60 Hz 兩側的間諧波

電壓近似固定，電流振幅跟著功率走，等於 60 Hz 載波被 GPU 方波**調幅（AM）**：

```
i_a(t) = √2 · I(t) · cos(ω₀t)
I(t)   = P(t) / (√3 · V_LL)
P(t)   = P̄ + Σ c_k · cos(2π · k · f_m · t)
⇒ 間諧波位於 f₀ ± k·f_m，幅值 ≈ c_k / (2P̄)
```

以 35 ↔ 100 MW、T_iter 1.4 s（f_m = 0.71 Hz）、計算占比 64% 為例（理想方波＋5 ms 一階邊緣解析值）：

| k | 電網電流頻率 | 幅值 |
|---|---|---|
| 1 | 59.29／60.71 Hz | −12 dBc |
| 2 | 58.57／61.43 Hz | −19 dBc |
| 3 | 57.86／62.14 Hz | −33 dBc |
| 17 | 47.9／72.1 Hz | −45 dBc |

在發電機**轉子座標**裡，這些邊帶就是 k·f_m 的**電磁轉矩脈動**。k = 17 對應 12.1 Hz，正落在汽輪機**軸系扭振**頻段；幅值雖小，但軸系阻尼常低於 1%，長期會累積高週疲勞。

**邊緣時間決定諧波延伸多高**：轉角約 1／(π·t_r)。5 ms 邊緣 → 約 64 Hz，已涵蓋軸系扭振頻段。所以補償不能只做低頻平滑，頻寬要蓋到幾十 Hz。

## 1.3 AI 負載頻譜與電網敏感頻段重疊

| 頻段 | 範圍 | 說明 |
|---|---|---|
| AI 負載主能量 | 0.2–3 Hz | arXiv 2508.14318 |
| 邊緣諧波延伸 | 至約 64 Hz（5 ms 邊緣） | 本專案估算 |
| 區間／長線路模態 | 0.16–1 Hz | 同上 |
| 區域擺盪模態 | 0.5–5 Hz，共振可放大約 50% | Siemens Energy（ERCOT 2025/8 簡報） |
| 軸系扭振 | 5–55 Hz（Siemens）／7–100+ Hz（論文） | — |
| 規範範例帶 | 0.1–20 Hz 能量 ≤ 20% | arXiv 2508.14318 |

**弱電網**會把 2–3 倍的波動傳到機組端；設備商建議機端波動壓到約 1–2%、ramp 壓到約 10%/s 以下。台灣電網相對孤立，這點要特別注意。

## 1.4 對電網的三種風險

1. **共振與機組疲勞**：週期性擺盪誘發次同步共振、區間振盪與電壓閃變。2019 年佛州曾出現約 200 MW 的振盪源事件，AI 叢集擺盪規模可以更大。
2. **電壓擾動下集體脫網**：2024/7/10 北維吉尼亞 230 kV 避雷器故障，82 秒內 6 次故障，約 60 座資料中心、1,500 MW 同時轉供備援；重複故障後不自動回接，負載離網數小時，調度只能緊急降低發電。
3. **法規快速收緊**：NERC 2026/5/4 發布 Level 3 必要行動警示（計算型負載），要求建模、穩定度研究與通訊；ERCOT NOGRR282 訂定大型計算負載電壓／頻率穿越要求（2026/6 董事會通過、待 PUCT 核定）。台電規範是否跟進：**待確認**。

## 1.5 一句話

GPU 同步擺盪把負載變成高頻方波：在 AC 端表現為**電流漣波（間諧波）**，在事件層級表現為**ramp 與穿越問題**。飛輪負責吸收快的部分，電網只負責平均值和慢的部分。詳見 [04 控制設計](./04-control-design.md)。
