# 07 · 飛輪 SOH 怎麼估

**飛輪的「容量」基本不衰退，老化出在機械和電氣部件。**所以飛輪的 SOH 不是一個容量百分比，而是由幾個子項組成的健康度，比較接近預測性維護（PHM）和剩餘壽命（RUL）估計。

## 7.1 和鋰電池的根本差異

| | 鋰電池 | 飛輪 |
|---|---|---|
| SoE 怎麼得到 | 要估：庫倫計數加 OCV 校正，會漂移 | 直接量：SoE = (ω² − ω²_min)／(ω²_max − ω²_min)，不會漂移 |
| 主要老化機制 | 化學衰退，容量和內阻一起變差 | 轉子疲勞、軸承磨耗、真空劣化、磁鐵退磁、電力電子熱循環 |
| 容量會不會掉 | 會，連續地掉 | J 不變，容量幾乎不掉；只有在主動降低 ω_max（derating）時才會減少 |
| 壽命怎麼結束 | 容量低於 70–80% | 某個部件到壽：換軸承、真空泵大修；轉子疲勞用完就強制降速或除役 |

## 7.2 「里程反推」的對應：轉子疲勞計數

轉子環向應力 σ ∝ ω²，轉速歷程就是應力歷程：

1. 把 ω²(t) 換成 σ(t)，做 **rainflow** 循環計數。
2. 用 **Miner 線性累積法則**算損傷：`D = Σ nᵢ / Nᵢ(Δσᵢ, σ_mean,i)`，Nᵢ 查轉子材料 S-N 曲線，並做平均應力修正（Goodman）。
3. 轉子剩餘疲勞壽命：`SOH_rotor = 1 − D`。

也可寫成應力加權的等效滿循環數（飛輪版 EFC）：`EFC_eq = Σ (Δσᵢ / Δσ_full)^m`，m 由材料 S-N 斜率決定。

以單機 500 kW／5 kWh、7,500–15,000 rpm 估算：

- J = 2E／(ω²_max − ω²_min) ≈ 19.5 kg·m²
- 滿轉速儲能 ½Jω²_max ≈ 6.7 kWh
- AIDC 每次擺盪單機約進出 37.5 Wh → Δσ／σ_max ≈ 0.56%

**結論**：每秒一次的微循環一年雖有上千萬次，但應力幅度極小，對轉子疲勞的貢獻可忽略。損傷主要來自大幅度的 SoE 變動（作業啟停、LVRT 支撐、每日 SoE 管理），rainflow 只需認真處理大循環。這也是飛輪適合 AIDC 的量化理由。

## 7.3 線上參數辨識：抓劣化趨勢

能量平衡：`P_dc − Jω·dω/dt = P_loss(ω) + P_conv_loss`

損耗模型 `P_loss(ω) ≈ a + b·ω + c·ω²`，以 RLS 線上辨識；或利用待機／維護窗做惰轉試驗（spin-down）：`−Jω·dω/dt = P_loss(ω)`。

| 監測量 | 劣化代表什麼 |
|---|---|
| c 項（風阻）上升 | 真空度變差（比對真空計讀值與真空泵運轉比） |
| a、b 項（摩擦、渦流）上升 | 軸承磨耗；磁浮軸承看控制電流是否上升 |
| 反電動勢常數 Ke = V_emf／ω 下降 | 永磁體退磁，通常是過溫造成 |
| 振動頻譜：1× 轉速分量變大、固有頻率偏移 | 轉子不平衡變大；複合材料轉子剛性下降或脫層（早期指標） |
| 單次循環的來回效率下降 | 整體損耗變大 |
| J_est = ∫P dt／Δ(½ω²) | 正常應為常數；漂移先查量測，再查轉子 |
| IGBT／SiC 的 Vce_on 或 Rds_on、ΔTj 的 rainflow、直流電容 ESR | 電力電子老化（與 BESS PCS 做法相同） |
| 磁浮系統備援軸承落地次數 | 每次落地都扣壽命，硬性上限 |

## 7.4 建議的 SOH 定義：多維度，取最小值

- **SOH_E（容量）** = 目前允許可用能量／出廠可用能量。正常 100%，轉子疲勞時因降速而下降。
- **SOH_η（效率／待機損耗）** = P_loss,出廠(ω_ref)／P_loss,目前(ω_ref)
- **SOH_life（剩餘壽命）**：轉子 1 − D_rotor；機械軸承看 L10 壽命消耗比例；電力電子看熱循環損傷。

整機 SOH 取 `min(各安全相關子項)`，不用加權平均。轉子屬爆裂風險件，SOH_rotor 下降時要觸發 ω_max 降額；SOH_η 主要影響營運成本和排程。

**一句話**：鋰電池的 SOH 看容量掉了多少；飛輪看的是「能量流不變，但損耗、振動、疲勞累積了多少」，做法以狀態監測和損傷計數為主。
