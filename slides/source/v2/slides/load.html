GPU 訓練負載：同步方波，邊緣只有幾毫秒

作業啟動

checkpoint

異常中止

邊緣 t_r ≈ 數 ms

計算 ≈ TDP

通訊 ≈ idle

週期性擺盪

計算時接近 TDP、all-reduce 時接近 idle；約每秒一次到每數十秒一次，視作業規模而定。

規模

GPU 占伺服器功率 >50%（GB200）；單一作業可超過 10 萬張 GPU，一座機房擺盪可達數十 MW。

尖峰與階躍

約 50 ms 的 EDP 尖峰可達 1.1×TDP；啟停、checkpoint、故障恢復造成作業級階躍。

工程含意：邊緣 t_r 決定諧波延伸，轉角約 1／(π·t_r)；5 ms 邊緣 → 約 64 Hz，已涵蓋軸系扭振頻段。

來源：Choukse et al., Power Stabilization for AI Training Datacenters（arXiv 2508.14318）　·　3

論文把 GPU 的行為講得很清楚：計算階段 tensor core 滿載接近 TDP，通訊階段做 all-reduce 或 checkpoint 時接近 idle，週期從一秒一次到幾十秒一次。GB200 上 GPU 占伺服器功率一半以上，單一作業可超過十萬張卡。還有 50 毫秒等級的 EDP 尖峰，以及啟停和故障恢復的階躍。我特別加了一個工程觀點：方波的邊緣時間決定諧波延伸到多高，5 毫秒的邊緣，諧波一路延伸到 60 幾 Hz，已經涵蓋汽輪機軸系扭振的頻段。所以不只看擺盪週期，也要看邊緣多陡。
